GhostScreen 95

Der Bildschirm, den es nicht gibt.

Ihr Headless-PC hat gerade einen Monitor bekommen. Einen Geistermonitor. In 4K.
Eine einzige EXE · Keine Installer · Kein Internet nötig · Windows 10/11 x64

⬇ GhostScreen-1.1.0.exe herunterladen Quellcode auf GitHub

Das Problem

Ihre Maschine ist eine Headless-Box: ein Server im Rack, ein Laptop mit kaputtem Bildschirm, eine Workstation per RDP oder Chrome Remote Desktop. Kein physischer Monitor — also gibt Ihnen Windows keinen Monitor.

  • Remote-Sitzungen bleiben bei einem unscharfen 800x600 (oder schlechter)
  • Apps, die nachweislich Vollbild sind, zeigen ein kleines zentriertes Fenster
  • Spiele, Design-Tools und Mediaplayer weigern sich, richtig zu rendern
  • Die UI-Skalierung lässt alles wie eine Tabellenkalkulation von 1993 aussehen

Sie kaufen doch keinen Monitor für eine Maschine, die Sie nie ansehen. Also was tun?

Die Lösung

GhostScreen 95 installiert einen virtuellen Bildschirm — einen Monitor, der nur in Software existiert — und stellt die Auflösung Ihrer Wahl ein:

2560x1440empfohlen
1920x1080Full HD
1366x768Laptop-Standard
1280x720HD ready

…alles mit 60 Hz (der Treiber unterstützt bis zu 4K). Das Betriebssystem glaubt, ein wunderschöner Monitor sei angeschlossen. Remote-Clients rendern Widescreen-Sitzungen in Full HD. Ihr Headless-PC benimmt sich wie ein normales Desktop — denn für Windows ist er eines.

"Ein Geisterbildschirm. Er ist da. Er ist nicht da. Niemand weiß es. Windows liebt ihn."

Was Sie bekommen

  • Eine EXE, alles drin — Treiber, Katalog, Einstellungen, Werkzeuge. Kein Installer, keine Reste.
  • Windows-95-Seele — eine treue '95er-Oberfläche. Farbverlauf-Titelleiste, gemeißelte Buttons, MS Sans Serif.
  • Selbstheilung — erkennt fehlende oder veraltete Treiber, installiert neu, startet den Bildschirm neu, versucht es erneut. Funktioniert nach einem Format.
  • Null Internet — alles läuft offline, direkt aus der EXE.
  • Wiederholbar — formatiert? Einfach wieder ausführen. Idempotent.
  • 7 Sprachen — italiano, español, français, deutsch, english, 中文, 日本語, automatisch erkannt.
  • Game-Boy-Musik — eine Chiptune spielt, während die Magie passiert. Stummschaltung unter Datei ▾.

Für wen

  • Headless-Server per RDP verwaltet — echte Auflösung, echte Produktivität
  • Laptops mit kaputtem Display — die Maschine ist nicht tot, sie braucht nur ein Geisterpanel
  • HTPCs an oft ausgeschalteten TVs — Desktop bleibt stabil
  • CI/CD- und Testlabore — stabile virtuelle Bildschirme für UI-Automation
  • Remote-Arbeit via Chrome Remote Desktop / AnyDesk / TeamViewer — gestochen scharfes Widescreen
  • GPU-Farmen und Mining-Rigs — der Software-Dummy-Plug
