GhostScreen 95

存在しないディスプレイ。

ヘッドレスPCに、モニターがやってきました。幽霊のやつが。4Kで。
単一のEXE · インストーラー不要 · インターネット不要 · Windows 10/11 x64

⬇ GhostScreen-1.1.0.exe をダウンロード GitHub でソースを表示

問題

あなたのマシンはヘッドレスボックス：ラックのサーバー、画面が壊れたノートPC、 RDP や Chrome リモートデスクトップで接続するワークステーション。物理モニターが ない——だから Windows はモニターなしをくれます。

  • リモートセッションはぼやけた 800x600（またはそれ以下）で頭打ち
  • 確実にフルスクリーンのはずのアプリが小さな中央寄せウィンドウに
  • ゲーム、デザインツール、メディアプレイヤーが正しく描画しない
  • UI スケーリングで全部が1993年の表計算ソフトみたいに見える

絶対に眺めないマシンのためにモニターは買えません。では、どうする？

解決策

GhostScreen 95 は仮想ディスプレイ——ソフトウェアの中にだけ存在する モニター——をインストールし、あなたが選んだ解像度に設定します：

2560x1440推奨
1920x1080フルHD
1366x768ノートPC標準
1280x720HD ready

…すべて 60 Hz（ドライバーは最大4K対応）。OS は美しいモニターが接続されていると 思い込みます。リモートクライアントはワイドスクリーンのフルHDセッションを快適に描画。 ヘッドレスPC は普通のデスクトップのように振る舞います——Windows にとってそうだからです。

"幽霊画面。ある。ない。誰も知らない。Windows はそれを愛している。"

手に入るもの

  • EXE1つに全部入り — ドライバー、カタログ、設定、ツール。インストーラー不要、残骸なし。
  • Windows 95 の魂 — '95年代に忠実なUI。グラデーションのタイトルバー、彫りの深いボタン、MS Sans Serif。
  • 自己修復 — ドライバーの欠落や陳腐化を検出し、再インストール、ディスプレイ再起動、再試行。フォーマット後も動作。
  • 完全オフライン — すべてEXEだけでオフライン動作。
  • 再実行可能 — フォーマットした？もう一度実行。冪等です。
  • 7言語 — italiano, español, français, deutsch, english, 中文, 日本語、自動検出。
  • ゲームボーイ音楽 — 魔法が起きている間、チップチューンが流れます。ファイル ▾ で消音可。

こんな人向け

  • ヘッドレスサーバーを RDP で管理 — 実解像度、実生産性
  • 画面が壊れたノートPC — マシンは死んでない、幽霊パネルが必要なだけ
  • HTPCが消えているテレビに接続 — デスクトップは常に正常
  • CI/CD・テストラボ — UI自動化のための安定した仮想ディスプレイ
  • リモートワーク — Chrome リモートデスクトップ / AnyDesk / TeamViewer でくっきりワイド画面
  • GPUファームとマイニングリグ — ソフトウェア製ダミープラグ
