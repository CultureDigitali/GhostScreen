GhostScreen 95

Il display che non esiste.

Il tuo PC headless ha appena ricevuto un monitor. Un fantasma. In 4K.
Un unico file EXE · Niente installer · Nessuna connessione necessaria · Windows 10/11 x64

Il problema

La tua macchina è una scatola headless: un server in un rack, un portatile con lo schermo rotto, una workstation raggiunta via RDP o Chrome Remote Desktop. Nessun monitor fisico — quindi Windows ti dà nessun monitor.

  • Le sessioni remote si fermano a un sfocato 800x600 (o peggio)
  • Le app che sai essere a tutto schermo mostrano una piccola finestra centrata
  • Giochi, tool di design e media player rifiutano di renderizzare correttamente
  • Lo scaling dell'interfaccia fa sembrare tutto un foglio di calcolo del 1993

Non puoi comprare un monitor per una macchina che non guarderai mai. Quindi cosa fai?

La soluzione

GhostScreen 95 installa un display virtuale — un monitor che esiste solo nel software — e imposta la risoluzione che scegli tu:

2560x1440consigliata
1920x1080Full HD
1366x768standard notebook
1280x720HD ready

…tutte a 60 Hz (il driver supporta fino a 4K). Il sistema operativo pensa che sia collegato un bellissimo monitor. I client remoti renderizzano sessioni widescreen in Full HD. Il tuo PC headless si comporta come un desktop normale — perché, per Windows, lo è.

"Uno schermo fantasma. C'è. Non c'è. Nessuno lo sa. Windows lo adora."

Cosa ottieni

  • Un solo EXE, tutto dentro — driver, catalogo, impostazioni, strumenti. Niente installer, niente residui.
  • Anima Windows 95 — un'interfaccia fedele all'epoca '95. Title bar sfumato, pulsanti cesellati, MS Sans Serif.
  • Auto-riparazione — rileva driver mancanti o obsoleti, reinstalla, riavvia il display, riprova. Funziona dopo un formato.
  • Zero internet — tutto gira offline, dal solo EXE.
  • Rieseguibile — hai formattato? Eseguito di nuovo. È idempotente.
  • 7 lingue — italiano, español, français, deutsch, english, 中文, 日本語, rilevate automaticamente.
  • Musica Game Boy — una chiptune suona mentre accade la magia. Disattivabile da File ▾.

A chi serve

  • Server headless gestiti via RDP — risoluzione reale, produttività reale
  • Portatili con schermo rotto — la macchina non è morta, le serve solo un pannello fantasma
  • HTPC collegati a una TV spesso spenta — desktop sempre a posto
  • Lab CI/CD e test — display virtuali stabili per l'automazione UI
  • Lavoro remoto via Chrome Remote Desktop / AnyDesk / TeamViewer — widescreen nitido
