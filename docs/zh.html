GhostScreen 95

不存在的显示器。

你的无头电脑刚刚获得一台显示器。一台幽灵显示器。支持4K。
一个 EXE 文件 · 无需安装程序 · 无需联网 · Windows 10/11 x64

⬇ 下载 GhostScreen-1.1.0.exe 在 GitHub 查看源码

问题

你的机器是一台无头主机：机架上的服务器、屏幕损坏的笔记本电脑、通过 RDP 或 Chrome 远程桌面访问的工作站。没有物理显示器——所以 Windows 给你一个显示器都没有。

  • 远程会话被限制在模糊的 800x600（或更差）
  • 你知道是全屏的应用只显示一个小窗口
  • 游戏、设计工具和播放器拒绝正确渲染
  • 界面缩放让一切都像 1993 年的电子表格

你不会为一台永远不会看的机器买显示器。那该怎么办？

解决方案

GhostScreen 95 安装一个虚拟显示器——一个只存在于软件中的显示器——并设置你选择的分辨率：

2560x1440推荐
1920x1080全高清
1366x768笔记本标准
1280x720高清

…全部支持 60 Hz（驱动程序最高支持 4K）。操作系统以为插着一台漂亮的显示器。 远程客户端流畅渲染宽屏全高清会话。你的无头电脑表现得像一台普通台式机——因为在 Windows 眼中，它就是。

"一块幽灵屏幕。它在那。它不在。没人知道。Windows 爱它。"

你将获得

  • 一个 EXE，一切尽在其中 — 驱动、目录、设置、工具。无需安装程序，无残留。
  • Windows 95 灵魂 — 忠实还原 95 年代界面。渐变标题栏、立体按钮、MS Sans Serif。
  • 自我修复 — 检测缺失或过时的驱动，重新安装，重启显示器，自动重试。格式化后也能用。
  • 完全离线 — 一切离线运行，仅凭这个 EXE。
  • 可重复执行 — 格式化了？再运行一次。幂等。
  • 7 种语言 — italiano, español, français, deutsch, english, 中文, 日本語，自动检测。
  • Game Boy 音乐 — 奇迹发生时播放芯片音乐。可在 文件 ▾ 中静音。

适合谁

  • 无头服务器通过 RDP 管理 — 真实分辨率，真实效率
  • 屏幕损坏的笔记本 — 机器没死，只缺一块幽灵面板
  • HTPC连接常关的电视 — 桌面始终正常
  • CI/CD 和测试实验室 — 稳定的虚拟显示器用于 UI 自动化
  • 远程办公通过 Chrome 远程桌面 / AnyDesk / TeamViewer — 清晰的宽屏
  • GPU 农场和矿机 — 软件版 dummy plug

六个完整案例：docs/CASE-STUDIES.md

快速开始

1. 下载 EXE · 2. 右键 → 以管理员身份运行 · 3. 选择分辨率 · 4. 点击安装并应用 · 完成。🎩

需要 Windows 10/11 x64 和内置的 .NET Framework 4.x（已预装）。MIT 许可证。
