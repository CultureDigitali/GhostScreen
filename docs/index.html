GhostScreen 95

The display that doesn't exist.

Your headless PC just got a monitor. A phantom one. In 4K.
One single-file EXE · No installers · No internet needed · Windows 10/11 x64

⬇ Download GhostScreen-1.0.0.exe View Source on GitHub

The problem

Your machine is a headless box: a server in a rack, a laptop with a broken screen, a workstation reached over RDP or Chrome Remote Desktop. No physical monitor — so Windows gives you no monitor at all.

  • Remote sessions cap at a blurry 800x600 (or worse)
  • Apps you know are fullscreen show a tiny centered window
  • Games, design tools and media players refuse to render properly
  • UI scaling makes everything look like a spreadsheet from 1993

You can't buy a monitor for a machine you'll never look at. So what do you do?

The fix

GhostScreen 95 installs a virtual display — a monitor that exists only in software — and dials in the resolution you choose:

2560x1440recommended
1920x1080Full HD
1366x768laptop standard
1280x720HD ready

…all at 60 Hz (the driver supports up to 4K). The OS thinks a beautiful monitor is plugged in. Remote clients happily render widescreen, full-HD sessions. Your headless rig behaves like a normal desktop — because, as far as Windows is concerned, it is one.

"A ghost screen. It's there. It isn't. Nobody knows. Windows loves it."

What you get

  • One EXE, everything inside — driver, catalog, settings, tools. No installer, no leftovers.
  • Windows 95 soul — a faithful '95-era UI. Gradient title bar, chiseled buttons, MS Sans Serif.
  • Self-healing — detects a missing or stale driver, reinstalls, restarts the display, retries. Works on a fresh format.
  • Zero internet — everything runs offline, from the EXE.
  • Re-runnable — you formatted? Run it again. It's idempotent.

Who it's for

  • Headless servers managed over RDP — real resolution, real productivity
  • Laptops with broken screens — the machine isn't dead, it just needs a phantom panel
  • HTPCs attached to a TV that's often off — keep the desktop sane
  • CI/CD and test labs — stable virtual displays for UI automation
  • Remote work via Chrome Remote Desktop / AnyDesk / TeamViewer — crisp widescreen
  • GPU farms and mining rigs — the software dummy plug

Six full stories: docs/CASE-STUDIES.md

Quick start

1. Download the EXE · 2. Right-click → Run as administrator · 3. Pick your resolution · 4. Hit Installa e Applica · Done. 🎩

Requires Windows 10/11 x64 and the built-in .NET Framework 4.x (preinstalled). MIT licensed.
