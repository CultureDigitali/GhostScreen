GhostScreen 95

L'écran qui n'existe pas.

Votre PC headless vient d'hériter d'un écran. Un fantôme. En 4K.
Un EXE unique · Sans installateur · Sans internet · Windows 10/11 x64

⬇ Télécharger GhostScreen-1.0.0.exe Code source sur GitHub

Le problème

Votre machine est une boîte headless : un serveur en rack, un portable à l'écran cassé, une station de travail atteinte par RDP ou Chrome Remote Desktop. Pas d'écran physique — donc Windows ne vous donne aucun écran.

  • Les sessions distantes plafonnent à un flou 800x600 (voire pire)
  • Les apps que vous savez en plein écran montrent une petite fenêtre centrée
  • Jeux, outils de design et lecteurs médias refusent de s'afficher correctement
  • La mise à l'échelle donne à tout l'air d'un tableur de 1993

Vous n'allez pas acheter un écran pour une machine que vous ne regarderez jamais. Alors ?

La solution

GhostScreen 95 installe un écran virtuel — un moniteur qui n'existe que dans le logiciel — et règle la résolution de votre choix :

2560x1440recommandée
1920x1080Full HD
1366x768standard portable
1280x720HD ready

…le tout en 60 Hz (le pilote gère jusqu'en 4K). Le système d'exploitation croit qu'un magnifique moniteur est branché. Les clients distants rendent des sessions widescreen Full HD. Votre PC headless se comporte comme un vrai bureau — parce que, pour Windows, c'en est un.

"Un écran fantôme. Il est là. Il n'est pas là. Personne ne sait. Windows l'adore."

Ce que vous obtenez

  • Un EXE, tout dedans — pilote, catalogue, paramètres, outils. Sans installateur, sans résidus.
  • Âme Windows 95 — une interface fidèle à l'époque '95. Barre de titre dégradée, boutons ciselés, MS Sans Serif.
  • Auto-réparation — détecte un pilote manquant ou obsolète, réinstalle, redémarre l'écran, réessaie. Fonctionne après un formatage.
  • Zéro internet — tout fonctionne hors ligne, depuis l'EXE.
  • Ré-exécutable — formaté ? Relancez-le. C'est idempotent.
  • 7 langues — italiano, español, français, deutsch, english, 中文, 日本語, détectées automatiquement.
  • Musique Game Boy — une chiptune joue pendant la magie. Coupez-la dans Fichier ▾.

Pour qui

  • Serveurs headless gérés en RDP — vraie résolution, vraie productivité
  • Portables à écran cassé — la machine n'est pas morte, il lui faut un panneau fantôme
  • HTPC branchés sur une TV souvent éteinte — un bureau toujours sain
  • Laboratoires CI/CD et tests — écrans virtuels stables pour l'automatisation UI
  • Télétravail via Chrome Remote Desktop / AnyDesk / TeamViewer — widescreen net
  • Fermes GPU et rigs de minage — le dummy plug logiciel

Six histoires complètes : docs/CASE-STUDIES.md

Démarrage rapide

1. Téléchargez l'EXE · 2. Clic droit → Exécuter en tant qu'administrateur · 3. Choisissez la résolution · 4. Cliquez sur Installer et appliquer · Fini. 🎩

Requiert Windows 10/11 x64 et le .NET Framework 4.x intégré (préinstallé). Licence MIT.
